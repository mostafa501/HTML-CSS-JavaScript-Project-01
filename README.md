# HTML-CSS-JAVASCRIPT-PROJECT-01

A responsive and interactive website developed using **HTML5**, **CSS3**, and **JavaScript** as part of my new projects.

## Project Overview

This project is a front-end website created to practice and apply HTML, CSS, and JavaScript concepts. It focuses on building a structured, responsive, and interactive website by combining HTML for content structure, CSS for styling and layout, and JavaScript for dynamic functionality and user interactions.

The design is based on the [Leon PSD Agency Template](https://www.graphberry.com/item/leon-psd-agency-template#google_vignette) by Graphberry — a free PSD template featuring a modern, flat design and vibrant colors.

## Technologies Used

* **HTML5** – Website structure and content.
* **CSS3** – Styling, layouts, and responsive design.
* **JavaScript (ES6+)** – DOM manipulation and interactive functionality.
* **Font Awesome** – Icons.
